O que é o Zello

O Zello Saúde é um aplicativo mobile (Flutter) que conecta pacientes, profissionais de saúde e administradores em uma única plataforma. Ele permite:

  • Pacientes: Acessar prontuário completo, gerenciar medicações, consultas, exames, terapias, convênios, e interagir com um assistente de IA.
  • Profissionais: Gerenciar agenda, ver prontuários de pacientes atribuídos, registrar notas de sessão, encaminhamentos.
  • Administradores: Gerenciar profissionais, permissões, hospitais, visualizar dashboard com KPIs, e monitorar conversas de chat.

Row-Level Security (RLS)

Cada tabela tem políticas RLS que controlam quem pode ler/escrever. Três níveis de acesso:

Admin

Acesso total a todas as tabelas. Define permissões de outros profissionais.

Profissional

Acessa apenas dados de pacientes atribuídos. Suas permissões são controladas pela tabela permissions.

Paciente

Acessa apenas seus próprios dados. Pode ler, mas não editar dados clínicos.

Edge Functions (Supabase + Deno)

Funções server-side que rodam no Supabase e chamam a API da Anthropic Claude. A chave de API (ANTHROPIC_API_KEY) fica APENAS no servidor.

Funções Disponíveis

1. Chat QA (chat-qa)

Assistente de IA genérico com 3 modos:

  • qa: Perguntas sobre o app (como usar, recursos disponíveis)
  • exam: Análise de exame médico (upload de PDF ou imagem via base64)
  • plan: Análise de plano de saúde do paciente
// Exemplo de chamada (Flutter)
final response = await Supabase.instance.client.functions.invoke(
  'chat-qa',
  body: {
    'messages': [{'role': 'user', 'content': 'O que posso fazer no app?'}],
    'kind': 'qa',
  },
);

2. Análise de Convênio (analyze-convenio)

Analisa o plano de saúde do paciente e recomenda hospitais da rede credenciada. Retorna: lista de hospitais compatíveis, análise do plano, sugestão de ação.

3. Análise de Prontuário (analyze-prontuario)

Analisa todo o histórico clínico do paciente e retorna: resumo, pontos de atenção, sugestões de melhoria, cuidados preventivos, recomendações de estilo de vida, nível de risco geral.

4. Importação de Prontuário (import-prontuario)

Recebe texto extraído de um documento (PDF, imagem, TXT) e usa Claude para estruturar os dados em JSON: cirurgias, internações, sintomas, alergias, vacinas, medicações.

Convenções do Projeto

Arquitetura
  • Um provider por entidade (ex: patients_provider.dart)
  • Um model por entidade (ex: patient.dart)
  • Uma tela por arquivo (ex: home_screen.dart)
  • Widgets reutilizáveis ficam em zello_shared/widgets/
Padrões de Código
  • Todas as queries Supabase usam schema: 'zello'
  • Providers usam AsyncValue para loading/error/data
  • Models usam fromJson/toJson para serialização
  • RLS garante isolamento de dados por role
